# 随手账 iOS 客户端

[下载随手账 3.0.8 未签名 IPA](https://github.com/Qq20050817/suishou-ledger-ios-build/releases/download/v3.0.8/SuishouLedger-3.0.8-independent-unsigned.ipa)

适用于 iOS 和 iPadOS 26 及以上。使用原来的签名工具和同一证书覆盖安装，再运行「独立截图记账 V7」。如已关闭小票，可运行「继续上张截图记账」重新打开仍有效的草稿。核对后点确认才会入账。

本仓库包含客户端、离线拼音词典、虚构账单测试和发布工作流。个人账本和原始截图由独立服务验证登录权限后提供。离线词典的来源及许可证位于 `NativeReceipt/Sources/ReceiptCore/Resources/Pinyin-LICENSES.txt`。
